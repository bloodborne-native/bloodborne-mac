# Bloodborne for Apple Silicon 0.9.9

Controller buttons can be assigned in the launcher again.

What's new:

- **Controller buttons can be assigned in Controls, and the controller list works**
  ([#19](https://github.com/bloodborne-native/bloodborne-mac/issues/19)). The launcher reads
  controller buttons through a small helper inside the app, and since 0.9.0 the helper couldn't
  start: Assign showed "Couldn't save" with a `Library not loaded: @rpath/libSDL3.0.dylib`
  message, and Controls said no controller was found even while the game used it. The game
  itself always saw controllers; only remapping and the list were affected.

Change controls in the launcher's **Controls** tab, not in `bbport.ini`: the launcher writes that
file again each time the game starts.

## Known issues

- Blood on already killed enemies can look pale with bright edges after reloading a save.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.8 again from the releases page.

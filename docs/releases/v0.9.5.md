# Bloodborne for Apple Silicon 0.9.5

Shaders compiled ahead of time, fewer pauses the first time effects appear, a crash after long play
fixed, and keyboard keys can be assigned again.

What's new:

- **Compile shaders ahead of time**, a new setting on the **Recompiled code** page (Settings). The
  game prepares its shaders from your copy of the game the next time it starts, with progress on
  screen: a few minutes, once, and you can stop and continue later. New effects then stop pausing
  the game the first time they appear: in Iosefka's Clinic, 292 of the 300 shaders the game uses
  (97%) are ready before you play. It is off by default.
- **Shorter pauses the first time effects appear**, also without that setting: the renderer now
  compiles new shaders on several cores while the game plays, instead of one at a time. On an
  M3 Pro, a first play in Iosefka's Clinic from empty caches spent 7 seconds in long frames instead
  of 12, and the worst pause was 2 seconds instead of 4.
- **The game no longer stops after a long session with "GPU library assertion failed"**
  (`Unknown data_format=15`, exit code 23,
  [#11](https://github.com/bloodborne-native/bloodborne-mac/issues/11)). The game sometimes hands
  the GPU an out-of-date texture or buffer description; one with a format the PS4's GPU does not
  have is now treated as empty for that moment instead of closing the game.
- **Keyboard keys can be assigned in the launcher's Controls** on macOS 14 and later
  ([#12](https://github.com/bloodborne-native/bloodborne-mac/issues/12)). The launcher now reads
  the key itself, with Shift, Ctrl and Alt combinations, and controller buttons are read even when
  the small input window is behind the launcher.
- **A lighter start:** the game prepares its executable and patches itself, in memory, instead of
  running scripts that wrote about 300 MB of files at every start.
- **Aspect ratio Auto** also offers the screen's own ratio at 720, 1080, 1440 and 2160 lines, for
  displays whose ratio is not a usual one.

After updating, the game converts its shaders for Metal again once (the cache format changed), so
the first start takes a little longer.

If you built the recompiled code with 0.9.2, 0.9.3 or 0.9.4, it keeps working: nothing to do.

## Known issues

- Blood on already killed enemies can look pale with bright edges after reloading a save.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.4 again from the releases page.

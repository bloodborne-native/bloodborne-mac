# Bloodborne for Apple Silicon 0.10.0

The game needs much less memory with the Metal renderer.

What's new:

- **Low memory mode** (Graphics → Low memory mode). The GPU normally keeps the whole of the
  game's memory pinned, about 8.4 GB, even the parts the game never touches. With this mode on,
  it takes only what the game actually uses, as it uses it. On an M3 Pro at 1080p in Iosefka's
  Clinic, the memory the GPU counts fell from about 8.4 GB to about 3.6 GB, at the same frame rate
  and with the same picture. It grows as you visit more areas: about 6.8 GB after 50 minutes and
  two bosses, mostly textures.
  - It's off by default. On Macs with 16 GB of memory or less, Home suggests turning it on, with a
    button to the setting.
  - **16 GB Macs** get more room before the game slows down or freezes.
  - **8 GB Macs** may now show a picture where they used to stay black with only sound. This
    hasn't been tested on an 8 GB Mac yet, and a long session may still need more memory than
    such a Mac has. Reports are very welcome.
- **GPU memory freed properly.** Buffers the renderer was done with could stay alive for the rest
  of the session; they are now released.

## Known issues

See [Known issues](https://github.com/bloodborne-native/bloodborne-mac/blob/main/docs/guide/troubleshooting.md#known-issues)
in the troubleshooting guide.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.11 again from the releases page.

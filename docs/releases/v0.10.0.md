# Bloodborne for Apple Silicon 0.10.0

The game needs much less memory with the Metal renderer.

What's new:

- **Much less memory with the Metal renderer.** The GPU used to keep the whole of the game's
  memory pinned, about 8.4 GB, even the parts the game never touches. It now takes only what the
  game actually uses, as it uses it. On an M3 Pro at 1080p in Iosefka's Clinic, the memory Metal
  counts fell from about 8.4 GB to about 3.6 GB, at the same frame rate and with the same picture.
  It grows as you visit more areas: about 6.8 GB after 50 minutes and two bosses, mostly
  textures, where it used to start above 8.4 GB.
- **16 GB Macs** have more room before the game slows down or freezes.
- **8 GB Macs** may now show a picture where they used to stay black with only sound. This has
  not been tested on an 8 GB Mac yet; a long session may still need more memory than such a Mac
  has. Reports are very welcome.

## Known issues

- Blood on already killed enemies can look pale with bright edges after reloading a save.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.11 again from the releases page.

# Bloodborne for Apple Silicon 0.9.11

⌘Q quits the game again.

What's new:

- **⌘Q quits the game again**, as a key binding you can change
  ([#20](https://github.com/bloodborne-native/bloodborne-mac/issues/20)). Since 0.9.6 ⌘Q did
  nothing, because that release took the Command shortcuts away to stop the game closing when ⌘
  was touched while holding a key. ⌘Q is now **Controls → System → Quit the game**, ⌘Q by
  default, and you can assign another key or a Shift, Ctrl or Alt combination there. It quits only
  when Q is pressed with ⌘ already held, so touching ⌘ while holding a movement key still never
  closes the game.

## Known issues

- Blood on already killed enemies can look pale with bright edges after reloading a save.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.10 again from the releases page.

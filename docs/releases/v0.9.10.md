# Bloodborne for Apple Silicon 0.9.10

16:10 screens at 1920×1200 start again, and the Metal renderer is a little faster.

What's new:

- **A 1920×1200 output (16:10) no longer crashes at start.** Since 0.9.8 the game closed right
  away with exit code 139 at that size. A scene larger than 1080p needs more of the game's
  memory, and 1920×1200 got slightly too little. Every scene above 1080p now gets enough.
  0.9.7 and earlier did not show the crash because they rendered 16:10 outputs at 1080p by
  mistake; 0.9.8 fixed that and exposed this.
- **The Metal renderer is faster**, about 10% standing in Iosefka's Clinic on an M3 Pro (45 to
  50 FPS at native 1080p), from two contributions by classicrob: the renderer tracks exactly
  which memory each GPU step reads, so it waits less often, and it keeps more of its work
  together in one pass.

## Known issues

- Blood on already killed enemies can look pale with bright edges after reloading a save.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.9 again from the releases page.

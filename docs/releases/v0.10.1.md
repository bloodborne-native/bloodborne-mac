# Bloodborne for Apple Silicon 0.10.1

Fixes a black sky with streaks that could appear in 0.10.0 after some play.

What's new:

- **No more black sky with streaks.** 0.10.0 changed how the game's memory is given to the GPU
  with the Metal renderer, and after a while the sky could turn black with streaks (and other
  scenery could be drawn wrong). That change is undone for the normal mode; the Low memory mode
  never had it.
- **Low memory mode keeps a fixed budget.** It used to keep growing the more areas you visited.
  Now it keeps at most 2 GB of the game's memory for the GPU and lets go of what it hasn't used
  for longest, taking it back when needed. In Iosefka's Clinic the GPU memory stayed under
  2.8 GB, at the same frame rate.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.10.0 again from the releases page.
